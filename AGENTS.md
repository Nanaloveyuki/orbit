# Orbit Agent Instructions

Read [`docs/llm-guide.md`](docs/llm-guide.md) before making repository changes.

- Keep `README.md` English and user-facing.
- Keep the Simplified Chinese user guide in `docs/README-cn.md`.
- Do not put prompts, private conversation text, credentials, CI transcripts, or
  maintainer-only instructions in the root README.
- Use `docs/README.md` to classify new documentation before adding it.
- Preserve package boundaries and generated-file ownership.
- Run focused validation for the files you change and report unavailable checks.
